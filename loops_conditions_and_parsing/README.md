# Shell Loops, Conditions and Parsing

This directory contains bash scripts demonstrating various shell scripting concepts including loops, conditionals, and text parsing.

## Tasks

1. **1-for_best_school** - Display "Best School" 10 times using for loop
2. **2-while_best_school** - Display "Best School" 10 times using while loop
3. **3-until_best_school** - Display "Best School" 10 times using until loop
4. **4-if_9_say_hi** - Display "Best School" 10 times with "Hi" on 9th iteration
5. **5-4_bad_luck_8_is_your_chance** - Loop with bad luck/good luck messages
6. **6-superstitious_numbers** - Display numbers 1-20 with superstitious messages
7. **7-clock** - Display time for 12 hours and 59 minutes
8. **8-for_ls** - Display current directory contents (part after first dash)
9. **9-to_file_or_not_to_file** - Check and display information about a file
10. **10-fizzbuzz** - FizzBuzz challenge implementation
11. **11-read_and_cut** - Parse and display /etc/passwd information
12. **12-tell_the_story_of_passwd** - Tell a story based on /etc/passwd
13. **13-lets_parse_apache_logs** - Parse Apache logs for IP and status codes
14. **14-dig_the-data** - Group and sort Apache log data by occurrence

## Requirements

- Ubuntu 20.04 LTS
- All scripts must pass Shellcheck
- First line: `#!/usr/bin/env bash`
- Second line: Comment explaining the script

## Usage

Make scripts executable:
```bash
chmod +x <script-name>
```

Run scripts:
```bash
./<script-name>
```
